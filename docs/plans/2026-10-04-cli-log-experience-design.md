## 边界与资源

- 协议 I/O 保持同步，UI 编排保持异步；CLI 的日志筛选不影响 Core 返回结果。
- 错误显示由 CLI 异常出口负责一次，底层设备诊断带来源标记。读写期间即使 verbose 也不插入日志，失败后恢复输出。
- 文件日志按大小滚动；Debug 累计 64 个事件，或下次事件到来距上次刷新超过 250 ms 时刷新。阶段/错误立即刷新，Dispose 刷新余量；不记录 Sign/Digest/认证材料或完整命令 XML。不引入后台计时线程，静默期间末尾 Debug 可保留至下次事件或 Dispose。
- 人工资源输入继续不限时、可取消；无效路径可在本次请求中重新输入，非交互模式立即失败。

4. 审查生产代码重复与死代码，完整测试、Release 构建、diff 检查后提交。
5. 检查本地主工作区状态与祖先关系，安全合并到 main，验证合并结果；不自动推送远端。
