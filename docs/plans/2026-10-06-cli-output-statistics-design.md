# CLI 刷写统计与多行输出设计

日期：2026-10-06；任务：OUTPUT-01；基线 ce7eeba，工作区干净。用户已授权修复，明确分区与整个 XML 批次都需要正确统计。

## 目标与兼容性

- 分区写入保留名称、文件名、真实字节总量和最终 ACK 完成语义；显示毫秒，完成平均速度与用时取同一单调时钟快照。
- 每份 XML 与整个通配批次独立统计执行数、跳过数、实际写入字节、总用时与平均速度。平均速度为实际写入字节 / 对应完整执行用时，包含预检、设备命令等待；补丁等零字节批次不显示写入速度。
- 跳过明细逐条显示序号、命令、原因及分区/位置。缺少分区名时显示 LUN 与原 XML 起始扇区表达式、长度；允许安全计算时附加解析后的扇区位置，不为跳过条目新增命令或拒绝原本可跳过的条目。
- 设备命令映射一项一行并对齐箭头；审查通用帮助、连接信息、存储/分区、XML 汇总及进度，拆开当前压缩到一行的多个独立字段，保持原功能和设备证据边界。

## 已知实现与线路

- 当前 ProgressDisplay 对 Duration 取整数秒，小分区完成均显示零秒；步骤的 XML xblgpt 时间只是该条命令时间，并不是整份 XML 用时。用户提供的硬件日志含旧版固定“写入”标签，运行进程路径尚无证据。
- FirehoseScriptSkippedEntry 当前只含序号/命令/原因；Core 已解析有界 XML，可保留允许的 label/filename/LUN/start/count 元数据。未支持命令依旧跳过，不透传 XML。
- Program XML、RAW、最终 ACK、Sparse、Digest/VIP、取消、会话 gate 与旧句柄失效均保持现状；CLI 只统计和展示，不添加设备操作。

## 契约、资源与边界

- 为跳过 record 添加兼容的可选 init 元数据，保留现有位置构造函数；原始位置表达式有界且只用于诊断，不执行任意表达式。可解析的位置使用既有 FirehoseScriptParser.Evaluate，解析失败保留原文。
- 同步协议仍同步；CLI 用 TimeProvider 单调计时，可注入假时钟验证。资源和流所有权不变，元数据内存随有界 XML 条目数增长，不随镜像字节增长。
- 平均速度/用时共用精确 elapsed；零时长显示未知速度，禁止 NaN/Infinity。分区每次 Started 重置计时，完成始终显示且保留最终统计，不把传输到总量当作最终 ACK。
- 多行进度按实际行数清理，换行与宽字符计数一致；输入元数据的控制字符显示为空格，避免终端控制序列。用户文本与模板双语资源化，不输出完整 XML/认证材料。
